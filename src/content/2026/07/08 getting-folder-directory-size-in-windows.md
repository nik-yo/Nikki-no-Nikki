# Getting Folder/Directory Size in Windows
::

<br/>

My computer is running low on storage, so I'm looking for an efficient way to retrieve list of folders and their size.

<br/>

Apparently the easiest is to use separate application. I used [https://windirstat.net/]{.text-blue-600} and managed to find folders that I can clean up.

<br/>

Alternatively, the online community has good experience with [https://www.jam-software.com/treesize]{.text-blue-600}.
