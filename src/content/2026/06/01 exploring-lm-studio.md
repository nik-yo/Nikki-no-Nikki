# Exploring LM Studio
::

<br/>

Today, I explored LM-Studio as it was introduced by my boss since I played with Ollama before.

<br/>

I was able to install it easily in my Macbook using `brew`{.bg-gray-200 .p-2 .rounded} and in Windows using `winget`{.bg-gray-200 .p-2 .rounded}. But for somewhat reason, I can't get it to work in my Linux machine.

<br/>

There are a few features that caught my attention:
1. UI is really clean.
2. It comes with a lot of information about the AI model. This might be because I enabled the developer mode.
3. I can download new model right from the app itself.
4. It also provides list of endpoints for REST call which is really nice.
5. Before I download a model, it will let me know if the model is too big for my machine to handle. This is a big help.

<br/>

Check it out at [https://lmstudio.ai/]{.text-blue-600}
